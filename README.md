# ⚡ SchemaGenie: AI SQL Architect & Optimizer

SchemaGenie helps developers and data analysts write and fix SQL queries fast.

Live App: [Try SchemaGenie Here](https://schemagenie-agent-ebxkjb3mbgg4creudkhwdf.streamlit.app/)

---

## What It Does

1. **English to SQL:** Type what data you need in plain English, and SchemaGenie writes the complete SQL query for PostgreSQL, MySQL, SQLite, or Snowflake.
2. **Fix Slow Queries:** Paste a slow query, and SchemaGenie spots what is slowing it down, rewrites it to run faster, and tells you which indexes to create.

---

## Built With

* **Python**
* **Streamlit** (for the web app)
* **Open-source LLMs** (for generating and optimizing SQL)
